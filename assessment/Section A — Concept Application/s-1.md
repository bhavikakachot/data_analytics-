## Handling Missing Delivery Times and Fixing Customer Ratings

### `delivery_time_mins`

I would use imputation rather than dropping rows. Since 14% of the 50,000 orders are missing delivery times, dropping them would remove approximately 7,000 records and could reduce the dataset's representativeness. This is a large enough proportion that row deletion may bias later analyses, especially if missingness is related to order characteristics.

The choice between mean and median should be based on the distribution of delivery times. Delivery times are often right-skewed because a small number of unusually delayed orders can create very large values. I would check the skewness first:

```python
df["delivery_time_mins"].skew()
```

If the column is approximately symmetric, I would fill missing values with the mean. If it is noticeably skewed, I would use the median because it is less affected by extreme delays and better represents a typical order:

```python
delivery_skew = df["delivery_time_mins"].skew()

if abs(delivery_skew) <= 0.5:
	fill_value = df["delivery_time_mins"].mean()
else:
	fill_value = df["delivery_time_mins"].median()

df["delivery_time_mins"] = df["delivery_time_mins"].fillna(fill_value)
```

For a clearly right-skewed delivery-time distribution, my final choice would therefore be median imputation. I would also record the imputation rule and, where the analysis is sensitive to imputed values, consider adding an indicator showing which rows were originally missing.

### `customer_rating`

Before analysis, I would convert the column to a numeric type. `pd.to_numeric` handles values such as `'4.5'` correctly. Using `errors="coerce"` converts invalid or non-numeric entries to `NaN`, which can then be inspected and handled explicitly rather than silently corrupting the analysis.

```python
import pandas as pd

df["customer_rating"] = pd.to_numeric(
	df["customer_rating"],
	errors="coerce"
).astype("float64")

# Inspect values that could not be converted.
invalid_ratings = df["customer_rating"].isna().sum()
print(f"Invalid or missing ratings: {invalid_ratings}")

# Confirm the resulting type before analysis.
print(df["customer_rating"].dtype)
```

If the column already contains genuine missing values, they remain `NaN`. I would investigate the coerced entries and then either remove those records for a rating-specific analysis or impute them using a documented rule. The important point is to complete numeric conversion before calculating averages, correlations, or other statistics.

## Choosing EDA Analysis Types and Seaborn Charts

### (a) Delivery time and customer rating

This is **bivariate analysis** because it examines the relationship between two numeric variables: `delivery_time_mins` and `customer_rating`. A suitable Seaborn chart is a regression plot:

```python
import seaborn as sns

sns.regplot(
	data=df,
	x="delivery_time_mins",
	y="customer_rating",
	scatter_kws={"alpha": 0.35}
)
```

The scatter points show the individual orders and their association, while the fitted trend line helps reveal whether ratings tend to increase or decrease as delivery time changes. A `regplot` is more appropriate than a simple line plot because delivery times are continuous observations rather than an ordered time series. Connecting observations with a line could imply a meaningful sequence between adjacent records and suggest changes that are not actually present. The correlation should also be supported with a numerical correlation coefficient, such as Pearson's or Spearman's correlation, as appropriate.

### (b) Average order value across restaurant categories

This is also **bivariate analysis** because it compares one numeric variable, `average_order_value`, with one categorical variable, `restaurant_category`. A suitable Seaborn chart is a box plot:

```python
sns.boxplot(
	data=df,
	x="restaurant_category",
	y="average_order_value"
)
```

A box plot shows the median, middle 50% of values, overall spread, and potential outliers for each restaurant category. This makes it useful for comparing both the typical order value and its distribution across categories. A simple line plot is inappropriate because restaurant categories are nominal rather than continuous or naturally ordered; connecting their values would imply a false progression from one category to the next. If only category averages were needed, a bar plot could summarise them, but it would hide the distribution and outliers that the box plot preserves.

Neither question is multivariate because each directly investigates only two columns. Univariate analysis would describe one variable at a time without examining its relationship with another variable.

## Identifying Surge Days with NumPy

Assume `order_counts` contains the 30 daily order totals and `revenue` contains the revenue for those same 30 days in the same order. I would calculate the mean and standard deviation, create the surge threshold, and compare every order count with that threshold:

```python
import numpy as np

order_counts = np.array([...])
revenue = np.array([...])

mean_orders = np.mean(order_counts)
std_orders = np.std(order_counts)
surge_threshold = mean_orders + 1.5 * std_orders

surge_mask = order_counts > surge_threshold
surge_orders = order_counts[surge_mask]
surge_revenue = revenue[surge_mask]
total_surge_revenue = np.sum(surge_revenue)
```

`np.mean` returns the average daily order count, while `np.std` measures how spread out the counts are around that average. A day is flagged only when its count is strictly greater than the mean plus 1.5 standard deviations.

The `surge_mask` is a Boolean NumPy array with one element for each day. Each element is `True` when the corresponding order count exceeds the threshold and `False` otherwise. Boolean indexing uses those values to select only the matching elements. Applying the same mask to `revenue` is important because it selects revenue from the same calendar days as the selected order counts, allowing `np.sum` to calculate total surge-day revenue.

This is vectorized array processing: NumPy applies the comparison and arithmetic element-wise across the entire array through optimized compiled operations, rather than requiring a Python `for` loop to inspect each day. It is generally faster than looping because it reduces Python interpreter overhead and operates on contiguous array data efficiently. It also makes the logic concise and reduces the risk of accidentally misaligning the order and revenue values.

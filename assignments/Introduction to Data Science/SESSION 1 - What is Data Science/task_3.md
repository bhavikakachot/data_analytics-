**A music streaming app** can collect data about the songs a user 
- listen,
- skips,
- likes,
- saves,
- adds to playlists.

 It can also identify the user’s favorite genres, artists, mood, and listening time. Using this data, the app recommends new songs with similar styles or songs liked by users with similar music tastes. 
 ### For example
 ---------------
  if a user often listens to Punjabi pop and likes upbeat songs, the app can create a personalized playlist with new Punjabi pop tracks. Spotify’s Discover Weekly similarly uses listening patterns and signals such as liked, followed, and saved music to improve recommendations.

## Web Server

**Definition:**

> **A web server is a computer or software that stores website files and delivers web pages to users through the Internet.**

## Working of Web Server:

- User enters a URL in a web browser.
- Browser sends a request to the web server.
- Web server finds the requested files.
- Server sends the webpage back to the browser.

## Types of Web Servers:

- **1. Apache**
  - Open-source and commonly used web server.

- **2. Nginx**
  - High-performance web server used for fast websites.

- **3. Microsoft IIS**
  - Web server developed by Microsoft.

- **4. LiteSpeed**
  - Fast and secure web server.

## Advantages of Web Server:

- **1. Website Storage**
  - Stores HTML, CSS, JavaScript, images, and other files.

- **2. Website Availability**
  - Makes websites accessible anytime through the Internet.

- **3. Fast Data Delivery**
  - Sends web pages quickly to users.

- **4. Security**
  - Provides security features like `HTTPS` and SSL.

- **5. Handles Multiple Users**
  - Can process requests from many users at the same time.

## Example:
User → Web Browser → Web Server → Website

## Simple Line:

> **A web server stores website files and provides them to users when they access a website.**

## Website

**Definition:**

> **A website is a collection of connected web pages stored on a web server and accessed through the Internet using a web browser.**

## Examples:

- `www.google.com`
- `www.youtube.com`
- `www.amazon.com`

## Types of Websites:

- **1. Static Website**
  - Contains fixed content that does not change frequently.
  - Built using `HTML` and `CSS`.
  - Example: Portfolio website.

- **2. Dynamic Website**
  - Content changes based on user interaction or data.
  - Uses databases and programming languages.
  - Example: Social media websites.

- **3. E-Commerce Website**
  - Used for buying and selling products online.
  - Examples: `Amazon`, `Flipkart`

- **4. Blog Website**
  - Used for sharing articles, news, and personal content.
  - Example: Personal blogs.

- **5. Business Website**
  - Provides information about a company and its services.
  - Example: Company websites.

- **6. Educational Website**
  - Provides learning materials and online courses.
  - Examples: Online learning platforms.

- **7. Social Media Website**
  - Allows users to communicate and share content.
  - Examples: `Facebook`, `Instagram`

- **8. News Website**
  - Provides latest news and updates.
  - Example: Online newspapers.

- **9. Portfolio Website**
  - Shows a person's skills, work, and achievements.
  - Example: Designer or developer portfolio.

- **10. Government Website**
  - Provides government services and information.
  - Example: Official government portals.

## Advantages of Websites:

- **1. Global Reach**
  - Provides information to users worldwide.

- **2. Easy Communication**
  - Helps businesses and people connect.

- **3. Online Services**
  - Supports shopping, learning, banking, and entertainment.

- **4. Information Sharing**
  - Allows sharing of text, images, videos, and documents.

## Simple Line:

> **A website is an online place where information, services, and content are available through the Internet.**

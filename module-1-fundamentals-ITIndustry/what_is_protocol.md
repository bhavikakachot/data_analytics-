## Protocol

**Definition:**

> **A protocol is a set of rules and standards that controls how data is transmitted and communicated between devices on a network.**

## Why Protocols are Used:

- Helps devices communicate correctly.
- Ensures data is sent and received properly.
- Provides security and reliability in communication.

## Types of Network Protocols:

- **1. HTTP (HyperText Transfer Protocol)**
  - Used to transfer web pages on the Internet.
  - Example: `http://website.com`

- **2. HTTPS (HyperText Transfer Protocol Secure)**
  - Secure version of HTTP.
  - Protects data using encryption.

- **3. FTP (File Transfer Protocol)**
  - Used to transfer files between computers.

- **4. TCP/IP (Transmission Control Protocol/Internet Protocol)**
  - Main protocol suite used for Internet communication.

- **5. SMTP (Simple Mail Transfer Protocol)**
  - Used to send emails.

- **6. POP3 (Post Office Protocol 3)**
  - Used to receive emails.

- **7. DNS (Domain Name System)**
  - Converts website names into IP addresses.
  - Example: `google.com → IP address`

- **8. DHCP (Dynamic Host Configuration Protocol)**
  - Automatically assigns IP addresses to devices.

## Advantages of Protocols:

- **1. Standard Communication**
  - Allows different devices to communicate.

- **2. Data Security**
  - Helps protect information during transfer.

- **3. Error Detection**
  - Finds and manages communication errors.

- **4. Reliable Data Transfer**
  - Ensures data reaches the correct destination.

## Simple Line:

> **Protocol = Rules that allow computers and devices to communicate with each other.**

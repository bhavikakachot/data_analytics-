## Microsoft Excel

**Definition:**

> **Microsoft Excel is a spreadsheet software used to store, organize, calculate, analyze, and visualize data in the form of rows and columns.**

## Features of Excel:

- **1. Data Entry**
  - Used to enter and store data in worksheets.

- **2. Formulas and Functions**
  - Performs calculations using formulas.
  - Examples: `SUM()`, `AVERAGE()`, `COUNT()`

- **3. Data Formatting**
  - Changes the appearance of data using fonts, colors, and styles.

- **4. Data Analysis**
  - Helps analyze large amounts of data.

- **5. Charts and Graphs**
  - Creates visual representations of data.

## Important Excel Tools:

- **1. Pivot Table**
  - Used to summarize and analyze large amounts of data quickly.
  - Helps find patterns and trends in data.

- **2. Pivot Chart**
  - Creates charts based on Pivot Table data.

- **3. Conditional Formatting**
  - Highlights important data using colors and rules.

- **4. Data Validation**
  - Controls what type of data can be entered in cells.

- **5. Filter**
  - Shows only required data from a large dataset.

- **6. Sort**
  - Arranges data in ascending or descending order.

- **7. VLOOKUP / XLOOKUP**
  - Finds and retrieves data from tables.

- **8. Power Query**
  - Used to import, clean, and transform data.

- **9. Power Pivot**
  - Used for advanced data modeling and analysis.

- **10. Macros (VBA)**
  - Automates repeated tasks in Excel.

## Common Excel File Extensions:

- `.xlsx` → Excel workbook
- `.xls` → Older Excel file
- `.csv` → Comma-separated data file

## Simple Line:

> **Excel is a spreadsheet tool used for data management, calculations, analysis, and reporting.**

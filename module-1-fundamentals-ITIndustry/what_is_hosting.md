## Web Hosting

**Definition:**

> **Hosting is a service that provides storage space on a server to store website files and make a website available on the Internet.**

## How Hosting Works:

- Website files are stored on a **web server**.
- When users enter a website address, the server sends the website data to their browser.
- Users can view and interact with the website.

## Types of Hosting:

- **1. Shared Hosting**
  - Multiple websites share resources on one server.
  - Example: Small websites and blogs.

- **2. VPS Hosting (Virtual Private Server)**
  - A single server is divided into multiple private servers.
  - Provides more control and performance.

- **3. Dedicated Hosting**
  - One complete server is used for a single website.
  - Suitable for large websites.

- **4. Cloud Hosting**
  - Uses multiple connected servers to host websites.
  - Provides flexibility and reliability.

- **5. WordPress Hosting**
  - Specially optimized for WordPress websites.

## Advantages of Hosting:

- **1. Website Availability**
  - Makes websites accessible 24/7.

- **2. Data Storage**
  - Stores website files, images, and databases.

- **3. Better Performance**
  - Provides server resources for faster loading.

- **4. Security**
  - Protects website data from threats.

- **5. Scalability**
  - Allows websites to handle more visitors.

## WWW (World Wide Web)

**Definition:**

> **WWW is a collection of websites and web pages that are connected through the Internet and can be accessed using a web browser.**

## Full Form:

- **WWW = World Wide Web**

## Introduced:

- **Year:** `1989`
- **Inventor:** `Tim Berners-Lee`

## How WWW Works:

- User sends a request through a **web browser**.
- The browser connects to a **web server**.
- The server sends web pages back to the user.

## Examples:

- `www.google.com`
- `www.wikipedia.org`
- `www.youtube.com`

## Advantages of WWW:

- **1. Easy Access to Information**
  - Provides information on different topics.

- **2. Global Communication**
  - Helps people communicate worldwide.

- **3. Online Services**
  - Allows online shopping, banking, learning, and entertainment.

- **4. Easy Sharing of Data**
  - Users can share documents, images, videos, and other information.

- **5. Business Growth**
  - Helps businesses reach customers globally.

## Difference Between Internet and WWW:

| Internet | WWW |
|---|---|
| A global network connecting computers | A service that provides websites and web pages |
| Includes email, file sharing, etc. | Uses browsers to access websites |

## Simple Line:

> **WWW is a system of connected web pages that allows users to access information through the Internet.**

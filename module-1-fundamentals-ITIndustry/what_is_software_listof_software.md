## Software

**Definition:**

> **Software is a collection of programs, instructions, and data that tells a computer how to perform different tasks.**

## Types of Software

- **1. System Software**
  - Manages computer hardware and system operations.
  - Examples: `Windows`, `Linux`, `macOS`

- **2. Application Software**
  - Helps users perform specific tasks.
  - Examples: `MS Word`, `Excel`, `Chrome`

- **3. Programming Software**
  - Used by developers to create and test programs.
  - Examples: `Visual Studio Code`, `PyCharm`, `Compiler`

- **4. Utility Software**
  - Helps maintain, protect, and optimize a computer.
  - Examples: `Antivirus`, `Disk Cleanup`, `Backup Tools`

- **5. Database Software**
  - Used to store, manage, and organize data.
  - Examples: `MySQL`, `Oracle`, `MongoDB`

- **6. Multimedia Software**
  - Used to create and edit audio, video, and images.
  - Examples: `VLC Media Player`, `Photoshop`, `Premiere Pro`

- **7. Web Application Software**
  - Runs through a web browser and provides online services.
  - Examples: `Gmail`, `Google Docs`, `Online Banking`

## Example

| Software Type | Purpose | Examples |
|---|---|---|
| System Software | Runs computer system | `Windows`, `Linux` |
| Application Software | User tasks | `Word`, `Excel` |
| Programming Software | Create programs | `VS Code`, `Compiler` |
| Utility Software | Computer maintenance | `Antivirus` |
| Database Software | Manage data | `MySQL`, `Oracle` |
| Multimedia Software | Edit media | `VLC`, `Photoshop` |

## Short Definition

> **Software is a set of instructions that helps a computer perform useful tasks.**

 ## **Data Analytics**
 1. **Data Analytics** is the process of collecting and analyzing data.
 2. It helps find useful patterns and meaningful information.
 3. These insights help people make better decisions.
 4. It is widely used in business, healthcare, education, and many other fields.

## what is data ?

Data is a collection of raw facts, figures, or observations that can be recorded and processed to produce meaningful information.

For example:

1. Numbers: 25, 100, 500
2. Names: Amit, Priya
3. Dates: 7 August 2026
4. Measurements: Temperature = 32°C
## **TYPES OF DATA**

## 1. Structured Data
Data that is organized in rows and columns.
Easy to store and analyze.

Examples:
```
- Excel spreadsheets
- SQL databases
- Customer records
```

## 2. Unstructured Data
Data that has no fixed format.
More difficult to analyze.

Examples:
```
- Images
- Videos
- Emails
- Social media posts
- Audio files
```

## 3. Semi-Structured Data
Data that is not fully organized but has tags or labels to provide structure.

Examples:
```
- JSON files
- XML files
- HTML documents
- Summary Table
```

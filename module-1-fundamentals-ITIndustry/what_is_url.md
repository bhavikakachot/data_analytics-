## URL (Uniform Resource Locator)

**Definition:**

> **URL is the address of a webpage or resource on the Internet that helps users locate and access it.**

## Full Form:

- **URL = Uniform Resource Locator**

## Example:

`https://www.google.com`

## Parts of URL:

- `https` → Protocol used for communication
- `www` → World Wide Web
- `google.com` → Domain name
- `/search` → Path of a webpage

## Types of URL:

- **1. Absolute URL**
  - Complete address of a webpage.
  - Example: `https://www.example.com/about`

- **2. Relative URL**
  - Short address used within the same website.
  - Example: `/about.html`

## Advantages of URL:

- **1. Easy Access**
  - Helps users open websites quickly.

- **2. Resource Identification**
  - Gives a unique address to web pages and files.

- **3. Easy Sharing**
  - Allows users to share web links.

- **4. Better Navigation**
  - Helps users move between different pages.

## Simple Line:

> **URL is a web address used to find and access information on the Internet.**
